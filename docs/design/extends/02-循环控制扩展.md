# 02 循环控制扩展

> 文档补充日期：2026-10-05
> 实施日期：2026-10-05
> 状态：已实施（Language Extension v1.2）
> 适用范围：C# / TypeScript 双语言核心，JavaScript / C# / Blazor 三种运行与调试后端，Visual Studio / VS Code / Monaco Playground 三类编辑表面

## 0. 功能范围

本分册只覆盖：

- `Break`
- `Continue`

并默认依赖 [01-过程与作用域扩展.md](./01-过程与作用域扩展.md) 已定义的过程、局部变量与调用帧模型。

## 1. 语言契约

### 1.1 语法与作用域

- `Break` 与 `Continue` 都是保留字
- 二者都只作用于**最近一层** `While` 或 `For`
- 二者都不带表达式、不带标签、不带目标名称
- 允许出现在 Main、`Sub`、`Function` 中，只要语法位置位于循环体内部
- 写在循环外立即报诊断

### 1.2 运行语义

| 关键字 | 语义 |
|---|---|
| `Break` | 立即结束最近一层 `While` / `For`，跳到对应 `EndWhile` / `EndFor` 之后的第一条用户语句 |
| `Continue` in `While` | 立即回到当前 `While` 的条件重算位置 |
| `Continue` in `For` | 跳过本轮剩余语句，但**仍会执行本轮尾部的 `Step` / 自增与边界检查** |

示例：

```smallbasic
For I = 1 To 10 Step 2
  If I = 5 Then
    Continue
  EndIf

  If I > 7 Then
    Break
  EndIf

  Sum = Sum + I
EndFor
```

## 2. 编译器与运行时实现

### 2.1 编译器改动

两套编译器都做了同构扩展：

- scanner / token kind / display string 新增 `Break`、`Continue`
- parser 新增对应 statement syntax
- binder 增加 loop context 栈，进入 `While` / `For` 体时 push，退出时 pop
- `Break` / `Continue` 绑定为显式 loop-control statement，而不是在 binder 阶段提前抹平成普通 `GoTo`

### 2.2 发射与执行模型

推荐且已采用的模型是“**复用既有 jump lowering**”：

```text
LoopEmitContext
  BreakLabel
  ContinueLabel
```

关键点：

- `Break` 发射为跳到 `BreakLabel` 的无条件跳转
- `Continue` 发射为跳到 `ContinueLabel` 的无条件跳转
- `While` 的 `ContinueLabel` 指向条件重算入口
- `For` 的 `ContinueLabel` 指向尾部自增 / `Step` / 边界检查之前，而不是循环头部

因此：

- 不需要新增 VM 帧模型
- 不需要新增调试 scope 结构
- 不改变 locals / globals / `Return` 的既有规则

### 2.3 诊断

| 场景 | 诊断 |
|---|---|
| `Break` 位于任何 loop 之外 | `BreakOutsideLoop` |
| `Continue` 位于任何 loop 之外 | `ContinueOutsideLoop` |
| 关键字后仍有多余 token | 复用现有 unexpected token / EOL 诊断 |

## 3. 调试器要求

`Break` / `Continue` 虽然只是控制流跳转，但必须像普通用户语句一样可调试：

- 可执行行探测要把两者所在行视为可停靠语句
- 内部 lowering 生成的 label、自增、边界检查不能额外暴露成用户可见停点
- 在 `Break` 行执行 `next`，应停在 loop 之后的下一条用户语句
- 在 `Continue` 行执行 `next`：
  - `While`：停在下一轮第一条用户语句或 loop 之后
  - `For`：先执行既有 increment / `Step` / 边界检查，再决定下一停点

## 4. 编辑器与语言服务

### 4.1 着色与补全

所有编辑表面都需要：

- 把 `Break` / `Continue` 着色为关键字
- 在循环体内优先推荐二者
- 提供简短 snippets / completion detail

### 4.2 Hover 与语义服务

- `Break` hover：退出最近一层 `While` / `For`
- `Continue` hover：进入最近一层 `While` / `For` 的下一轮；在 `For` 中仍执行尾部步长逻辑
- Outline / 导航栏 / Document Symbols 不新增 symbol kind
- 定义/引用/rename 不对这两个关键字提供符号级支持

## 5. 能力握手、测试与状态

### 5.1 capability

该扩展建议并已在设计上配套 `loop-control-v1` capability，用于防止编辑器接受新语法而外部旧宿主仍按旧能力运行。

### 5.2 测试覆盖

主要回归面：

- TS：`packages/smallbasic-lang-core/tests/language-extension.spec.ts`
- TS 服务：`packages/smallbasic-language-services/tests/service.spec.ts`、`semantic-tokens.spec.ts`
- C#：`tests/SmallBasic.Compiler.Tests/Runtime/LanguageExtensionTests.cs`

### 5.3 实施结论

`Break` / `Continue` 已在两套编译器、三后端调试链与三类编辑表面完成同步落地。后续功能点新增时，应继续把它们视为“普通可执行语句”，而不是宿主层面的特殊控制命令。
