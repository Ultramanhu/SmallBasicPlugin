# 03 整除与取余扩展

> 文档补充与实施日期：2026-10-06
> 状态：已实施（Language Extension v1.3）
> 适用范围：C# / TypeScript 双语言核心，JavaScript / C# / Blazor 三种运行与调试后端，Visual Studio / VS Code / Monaco Playground 三类编辑表面

## 0. 功能范围

本分册覆盖：

- `A \ B`
- `A Mod B`
- `Math.Div(A, B)`
- `Math.Mod(A, B)`

## 1. 语言契约

### 1.1 语义

| 语法 | 契约 |
|---|---|
| `A \ B` | 对实数商向零截断 |
| `A Mod B` | 返回与被除数同号的余数 |
| `Math.Div(A, B)` | 与 `A \ B` 等价 |
| `Math.Mod(A, B)` | 与 `A Mod B` 等价 |

当前已实施的 v1.3 契约中：

- `\`、`Mod`、`Math.Div`、`Math.Mod` 在除数为 `0` 时都返回 `0`
- `Mod` 不区分大小写，并作为保留字

> 注：这一点与 [04-GoSub与OnError错误处理.md](./04-GoSub与OnError错误处理.md) 中的 v1.4 提案存在潜在演进冲突。若后续实现统一 runtime error 模型，除零与非法数学运算可能从“返回 0”调整为“产生可处理的运行时错误”。

### 1.2 优先级与结合性

沿用 VB 风格优先级：

```text
* /  >  \  >  Mod  >  + -
```

同级从左到右结合。

示例：

```smallbasic
Whole = 17 \ 5
Rest = 17 Mod 5
TextWindow.WriteLine(Math.Div(-7, 2))
TextWindow.WriteLine(Math.Mod(-7, 2))
```

## 2. 双编译器与三运行后端实现

### 2.1 编译器改动

两套编译器都同步完成了：

- scanner/token kind 中新增 `Backslash` 与 `Mod`
- parser 中加入对应二元运算节点
- emitter 中发射：
  - `IntegerDivideInstruction`
  - `ModuloInstruction`

### 2.2 运行时改动

#### TypeScript

- `execution-engine.ts` 继续复用既有求值栈
- `runtime/libraries/math.ts` 增加 `Div` / `Mod`
- 运算指令层增加 `IntegerDivideInstruction` / `ModuloInstruction`

#### C#

- `Runtime/Instructions/OperatorInstructions.cs` 增加整数除法与取余指令
- `SmallBasic.Editor/Libraries/MathLibrary.cs` 增加 `Div` / `Mod`
- `Libraries.Interfaces.Generated.cs` / `Libraries.Generated.cs` 同步生成方法签名与包装

### 2.3 值语义

当前落地契约：

- `7 \ 2 = 3`
- `-7 \ 2 = -3`
- `7 Mod -2 = 1`
- `-7 Mod 2 = -1`
- `Math.Div` / `Math.Mod` 与运算符语义完全一致

## 3. 调试器与可执行行

这一扩展不新增新的帧或 scope，但要求：

- `\` / `Mod` 所在语句必须是可断点行
- 条件断点、Watch、Debug Console evaluate 都能求值 `Value \ 5`、`Value Mod 5`、`Math.Mod(Value, 5)`
- `Math.Mod` 在对象成员上下文中应按“库方法”而不是“运算符关键字”处理

## 4. 编辑器与语言服务

### 4.1 着色

- `Mod` 作为运算符时按关键字着色
- `Math.Mod` 中的 `Mod` 作为库方法名时按函数/方法着色
- `\` 由语义 hover 与解析器识别，不依赖 TextMate 单独分类

### 4.2 Hover / Signature Help / Completion

- `Mod` hover：说明余数语义与符号规则
- `\` hover：说明向零截断
- `Math.Div` / `Math.Mod` 走普通库方法的 signature help 与 hover

### 5.2 已实施结论

`\` / `Mod` 以及 `Math.Div` / `Math.Mod` 已在双编译器、三运行后端、三类编辑表面同步落地。当前契约仍以“除数为零返回 0”为准；若后续引入统一 runtime error 机制，需以 [04-GoSub与OnError错误处理.md](./04-GoSub与OnError错误处理.md) 为准重新修订本分册。
